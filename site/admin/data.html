Dataset upload

The predictor datasets are paid content, so they are not part of the public site. This page pushes them into Cloudflare KV, where the payment API serves them to verified buyers. You only need to do this once per dataset (and again whenever you update the data).

This must exactly match the ADMIN_SECRET environment variable on your Pages project.
